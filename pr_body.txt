## Summary

Adds a new documentation file (`docs/gemini-cli-file-scoping.md`) that explains how to control file and workspace scope in the **Gemini CLI** — specifically addressing the `Unknown arguments: all-files, allFiles` error and showing the correct alternatives (`--include-directories`, `@path` syntax, and `settings.json`).

## Context

This project integrates with Gemini via the **LLM API** (through `ChatGoogleGenerativeAI` in `agentbuilder/llm/gemini_llm.py`), which is distinct from the **Gemini CLI** (Google's interactive terminal tool). This guide helps contributors who use the Gemini CLI while working on the Agent Builder API project understand the difference and use the CLI correctly.
